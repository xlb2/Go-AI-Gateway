# 检索评测

比较关键词、向量与 RRF 混合检索的来源召回。评测不生成答案，不衡量回答正确率；真实 embedding 仅在三路对照中调用。

## 数据集

| 文件 | 用途 |
|---|---|
| `manifest.json` | `k0-corpus-v2`：18份文档的来源ID、逻辑路径与 SHA256 |
| `cases.json` | `k0-v2`：20道开发题、7道冻结保留题 |
| `corpus/` | 与清单校验值一致的固定原文副本 |
| `evaluator.go` | 查询词规划、source级评分与报告结构 |

语料包含6份标准来源 S01–S06，以及12份同领域干扰资料 D01–D12。题目、预期来源和人工判据不导入检索库。清单中的路径记录原始来源，实际读取位置为 `corpus/<path>`；`.gitattributes` 固定 LF，避免跨平台校验值变化。

**corpus 内的 Markdown 是冻结测试输入，不是项目使用文档。** 其中保留的旧状态、教学措辞、路径与链接用于固定评测条件，不随当前实现更新；阅读项目请使用仓库首页和 docs。更改语料须另建数据集版本，不能更新哈希掩盖漂移。

保留集 Q21–Q27 当前冻结，最终验收前不得执行 holdout split。原 Q15–Q20 曾用于发现向量评分口径问题，已并入开发集，不再作为独立盲测。保留集公开可见，独立性依赖评测流程，而非保密。

## 运行开发集

在仓库根目录的 WSL/Linux 中执行：

```bash
docker compose up -d mysql
bash scripts/eval-rag.sh
```

关键词评测只访问 MySQL，不需要模型密钥。三路对照另需在环境中配置 `EMBEDDING_BASE_URL`、`EMBEDDING_API_KEY`、`EMBEDDING_MODEL`，可选维度和批量大小见 [配置模板](../../.env.example)：

```bash
KNOWLEDGE_RAG_SPLIT=dev bash scripts/eval-rag-compare.sh
```

三路对照会为语料和查询调用真实 embedding，产生用量。两入口均显式使用 `knowledgeintegration,rageval` 标签，普通回归不会执行它们。测试校验原文 SHA256、创建随机测试库、导入固定资料，结束后删除测试库；报告写入已忽略的 `results/`。

## 对照方法

三路使用相同语料、题集与字符分段规则（800窗口、100重叠），按 source 级别取前5候选：

- 关键词：标识符与汉字双字词，去重最多32词；按不同命中词数排序，候选翻页收齐。
- 向量：取最多50个 chunk，按每个来源的最好分聚合后取前5，避免先取5个chunk再去重造成来源不足；候选截断仍可能限制来源覆盖。
- 混合：调用实际 HybridSearch 的 RRF 来源排名；向量分支候选仍受实现预算限制。

报告记录语料、题集与实现 SHA256、embedding 模型、规则及用量，便于核对运行条件。执行 PASS 只表示数据与流程检查通过，不以调低阈值换取质量通过。

| 指标 | 含义 |
|---|---|
| `macro_source_recall_at_5` | 可答题逐题计算找到的标准来源比例，再平均 |
| `macro_source_recall_at_1` | 第一名属于任一标准来源记1，否则记0，再对可答题平均 |
| `all_expected_sources_found` | 前5完整覆盖全部标准来源的可答题数 |
| `unanswerable_with_candidates` | 无答案题仍返回候选的数量，不等于已生成错误答案 |

## 开发集观察

18份语料、17道可答开发题；embedding 为 `text-embedding-v3`、1024维。2026-10-09 的三路结果：

| 指标 | 关键词 | 向量 | 混合 |
|---|---:|---:|---:|
| recall@5 | 0.765 | 0.824 | 0.912 |
| recall@1 | 0.412 | 0.588 | 0.706 |

2026-10-19 的关键词复现得到相同 recall@5，完整覆盖12/17题；3道无答案题均返回候选。当前没有拒答机制。原6份资料条件下 recall@5 曾饱和，且混合并非始终优于向量；新增干扰文档后才拉开该开发集的差距。

这些是用于迭代的小样本结果，不能外推为通用质量；来源召回也不证明片段足以支撑答案。实现取舍与已知限制见 [检索设计](vector-retrieval-design.md)。
