# CLI 测试

CLI 测试覆盖输入分派、终端编辑、流式显示与取消。使用方法见 [CLI 指南](../../docs/cli.md)。

## 自动回归

```bash
bash scripts/test-fast.sh -run 'CLI|CanceledTurn'
```

| 场景 | 检查内容 |
|---|---|
| 命令与对话 | 本地命令不请求模型，审批复用原入口，错误后可继续输入 |
| 显式多行输入 | 空行、命令样式正文、取消、EOF 与64KiB上限 |
| 交互编辑 | Linux PTY 下的光标、进程内历史、bracketed paste、Enter 提交边界及窗口缩放 |
| 终端恢复 | 提交、退出和空闲 Ctrl+C 后恢复 termios 与粘贴模式 |
| 输入回退 | 标准输入为管道时使用逐行读取 |
| 输出与推理 | 写失败传播，重定向输出降级，推理字段与最终回答隔离 |
| Harness 集成 | 多轮历史、工具进度、SDK 请求及 Redis 事件对应关系 |
| 运行中取消 | 下一轮等待收尾；部分回答持久化为中断，不伪造完成 |

`terminal_linux_test.go` 依赖 Linux PTY，仅在 Linux/WSL 编译；完整 Harness 场景位于 `test/e2e/`，需要 Redis。

## 终端手动检查

终端模拟器的剪贴板与渲染行为需要额外观察：粘贴多行后 Enter 前不得请求模型，Enter 后仅提交一次；粘贴 `/exit` 应作为正文；缩放后输入框与光标应正常；退出后终端应恢复回显。

真实模型手测需要单独配置服务。自动回归验证协议和状态，不替代所有终端模拟器的兼容性检查。
